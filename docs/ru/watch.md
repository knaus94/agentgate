# Панель

[English](../watch.md)

`agentgate watch` — живой вид того, что делает `/dev`, только для чтения. Запускается в любом терминале внутри
репозитория (в Zed — задача `agentgate: watch`). Панель не управляет задачами и не обращается ни к моделям,
ни к провайдерам.

## Что показывается

- **Задачи** — все задачи этого рабочего каталога из всех сессий Claude Code: сначала выполняющиеся, затем
  ожидающие (на паузе, готовые к вливанию), затем недавно завершённые. Режим, фаза, общее время, текущая
  операция. Клавиша `a` переключает на все рабочие каталоги машины.
- **Этапы** — операции, через которые прошла выбранная задача, по порядку и с длительностью; выполняющаяся
  помечена `▶`.
- **Воркеры** — разведчик, архитекторы, писатели, ревьюеры: модель, усилие и аккаунт, длительность запуска
  (и `×N`, если полоса запускалась несколько раз), а для работающего воркера — его последнее действие.
- **Проверки** — каждая объявленная проверка и актуален ли её результат.
- **Замечания** — открытые замечания по серьёзности и сколько из них блокируют.
- **Лимиты** — в заголовке, последнее известное использование каждой настроенной подписки.

## Как посмотреть внутрь

Перемещение — `↑` `↓` (или `j` `k`), переключение между списком задач и строками задачи — `tab`, открыть
строку — `enter`, назад — `esc`.

| Строка | Что открывается |
|---|---|
| воркер | его действия по мере выполнения: команды с концом их вывода, прочитанные и изменённые файлы, слова модели, итоговый отчёт. Вид следует за концом; прокрутка вверх останавливает слежение, `f` возобновляет |
| проверка | вывод её последнего запуска |
| замечания | каждое открытое замечание: серьёзность, место, свидетельство, влияние, способ исправления, решение триажа |
| план | бриф, потоки с файлами, принятый дизайн |

Действия берутся из потока событий, который каждый CLI пишет во время работы, поэтому это ровно то, что
делал воркер, а не пересказ. Длинные пути внутрь состояния самого инструмента сокращаются до `task:/…` и
`state:/…`.

`agentgate watch --once` печатает ту же картину обычным текстом — для скриптов и вывода не в терминал.
`--all` сразу открывает все рабочие каталоги.
