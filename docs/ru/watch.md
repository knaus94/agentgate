# Терминальная панель

[English](../watch.md) · [Командный интерфейс](cli.md)

`agentgate task watch` открывает живую панель задач Claude Code и Codex. Запускайте
её внутри репозитория или через задачу `agentgate: watch` в Zed. Прежняя команда
`agentgate watch` открывает ту же панель.

Панель только читает состояние. Она не управляет задачей, не запускает модели,
не обновляет квоты через API провайдеров и не сохраняет состояние шлюза. Её цель —
показать текущий этап, работу исполнителей и следующий шаг.

## Что отображается

| Раздел | Содержимое |
|---|---|
| Tasks | Сначала работающие задачи, затем требующие внимания, готовые изолированные изменения и недавно завершённые задачи. Режим, фаза, время и текущая операция |
| Stages | Принятые, текущая и оставшиеся части большой задачи; записанные операции и их длительность |
| Workers | Разведчики, дизайнеры, консультанты, авторы и ревьюеры: модель, усилие, аккаунт, длительность, повторные запуски и последнее действие |
| Checks | Объявленные команды проверки, последние результаты и актуальность доказательств относительно входных файлов |
| Findings | Открытые замечания по серьёзности, заметки и число блокирующих проблем |
| Signals | Механически найденные признаки, которые должен исследовать ревьюер |
| Plan | Краткое описание, потоки, принадлежащие им файлы и принятая архитектура |
| Заголовок | Выбранная область и последнее сохранённое использование подписок; новых запросов квот панель не делает |

В узком терминале строки задач и исполнителей занимают две строки. При небольшой
высоте область просмотра следует за выбранным элементом: проверки и исполнители
доступны даже ниже первоначального экрана. Размер можно менять во время работы.
Повреждённое или недоступное состояние показывается отдельной строкой с ошибкой,
а не вызывает падение или видимость отсутствия задачи.

## Клавиши

| Клавиша | Действие |
|---|---|
| `↑` / `↓` или `k` / `j` | Перейти между задачами или строками |
| `Tab`, `←` / `→` или `h` / `l` | Переключиться между списком задач и её элементами |
| `Enter` | Войти в задачу или открыть выбранный элемент |
| `Esc` / `h` | Вернуться из деталей |
| `PgUp` / `PgDn`, `Space` | Перейти на страницу |
| `Home` / `End`, `g` / `G` | В начало или конец списка; в деталях конец возобновляет слежение |
| `f` | Следить за новыми действиями исполнителя в открытых деталях |
| `a` | Переключить текущую рабочую копию и все копии |
| `r` | Обновить немедленно, включая актуальность проверок |
| `?` | Открыть подсказку по клавишам |
| `q` / `Ctrl-C` | Закрыть панель |

Открытая активность исполнителя следует за последними событиями. Прокрутка
останавливает слежение, `f` возобновляет его. Исполнитель привязан к каталогу
своего запуска, поэтому новая волна ревью не подменяет незаметно уже открытого
исполнителя.

| Открытый элемент | Детали |
|---|---|
| Исполнитель | Команды с концом вывода, прочитанные и изменённые файлы, сообщения модели и финальный отчёт |
| Проверка | Вывод последнего сохранённого запуска |
| Замечания | Серьёзность, место, доказательство, последствия, предлагаемое исправление и решение ведущего |
| Сигналы | Подсказки механического анализа, не выдаваемые за подтверждённые дефекты |
| План | Описание, задания и файлы потоков, принятый дизайн |

Активность читается из потока событий каждого CLI. Длинные внутренние пути
сокращаются до `task:/…`, `worktree:/…` и `state:/…`. Управляющие терминальные
последовательности из вывода исполнителей удаляются, включая команды буфера
обмена и заголовка окна. Вставленный текст не запускает клавиатурные команды.

## Обновление и актуальность

Активность исполнителей и состояние обновляются каждую секунду. Более дорогая
проверка актуальности доказательств выполняется не реже раза в пять секунд,
сразу при значимом изменении состояния и по клавише `r`. Навигация по строкам
не запускает повторное сканирование репозитория. Сам шлюз каждый раз проверяет
доказательства перед зависящей от них операцией: кеш панели не разрешает
завершение задачи.

## Текстовый и JSON-снимок

```sh
agentgate task watch --once
agentgate task watch --once --no-color
agentgate task watch --all
agentgate task watch --json
agentgate task watch --all --json
```

`--once` выводит один текстовый снимок и завершает процесс. Если stdin или stdout
не терминал, `watch` также не ждёт нажатий клавиш. `TERM=dumb` выбирает режим
снимка. `NO_COLOR` или `--no-color` выключает ANSI-цвета, сохраняя управление
клавишами в обычном терминале.

`--json` всегда возвращает один снимок для программной обработки. В нём есть
`schema_version` (сейчас `1`), `read_only`, `scope` и массив `tasks`. У задач есть
фаза, признак работы, исполнители, проверки, число блокирующих замечаний и
следующий шаг. Повреждённые задачи содержат поле `error`. Внутренние объекты Gate
и полные промпты исполнителей в снимок не включаются.

Без `--all` интерактивный и текстовый режимы автоматически покажут все рабочие
копии, если у текущей нет задач, а у других они есть. JSON-режим сохраняет явно
выбранную область: для всех копий нужен `--all`. Команда `task status --all`
возвращает прежний обзор текущей рабочей копии в исходном JSON-формате.
