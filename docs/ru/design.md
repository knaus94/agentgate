# Дизайн

[English](../design.md)

Поток может верстать по макету Figma, а гейт — сказать, получилось ли. Что вычислимо, вычисляют инструменты;
модель читает короткие результаты.

## Ход работы

| Шаг | Кто | Что происходит |
|---|---|---|
| Вход | вы, один раз | `agentgate figma login` открывает окно браузера. Сессия остаётся в профиле в `~/.local/share/agentgate/private`, который не видит ни один воркер. Ни токена, ни файла с куками |
| Выбор | лид | `agentgate figma frames <url>` перечисляет кадры страницы |
| Выгрузка | лид | `agentgate figma pull <url> --node <id> --out <dir>` пишет пакет макета |
| План | лид | `design [{package, url, root, stream, map}]` в плане |
| Замер | гейт | до начала работы страница сравнивается с пакетом: что отличается уже сейчас, задаче не засчитывается |
| Код | писатель потока | читает бриф (около двух тысяч токенов на секцию страницы) и сам запускает проверку вёрстки |
| Проверка | гейт | та же проверка вёрстки как объявленная. Новое расхождение блокирует ревью |
| Оценка | первый ревьюер | видит макет рядом со страницей и ищет то, чего не несут числа |

## Пакет

| Файл | Кто читает | Что внутри |
|---|---|---|
| `brief.md` | писатель, ревьюер | слои как намерение: правила раскладки, шрифт, цвет, токены |
| `frame.png` | писатель, ревьюер | картинка узла |
| `assets/` | писатель | иконки в SVG, картинки в PNG |
| `manifest.json` | гейт | источник, версия файла и дайджест содержимого: перевыгруженный макет делает прежние ревью устаревшими |
| `data/` | только инструменты | дерево узлов в формате REST Figma |

Экземпляр компонента — одна строка брифа, одинаковые соседи — один пункт списка, а положения, которые следуют
из автолейаута, не печатаются. `agentgate figma node <dir> <метка>` печатает один слой целиком.

## Что ловится и чем

| Расхождение | Чем ловится |
|---|---|
| положение, размер, радиус, шрифт, цвет, пропавший элемент | проверка вёрстки, без модели |
| неверная иконка, пропавший градиент или тень, обрезанный текст | ревьюер оси `design`, по двум картинкам |
| исключение, оправдывающее то, что продукту не нужно | тот же ревьюер, читая файл исключений |
| поведение | ревьюер корректности, тесты проекта и, если включена, браузерная проверка |

Проверка вёрстки находит текст по словам, а закрашенный блок — по положению, поэтому разметка в коде не нужна.
Слой судится относительно найденного родителя: съехавшая панель — одна находка, а не по одной на каждого ребёнка.

## Стенд и исключения

Проверка открывает страницу локального стенда. Страница должна быть в том состоянии, что показывает макет:
`agentgate fixtures <dir> --record <шлюз>` сохраняет ответы GraphQL настоящего шлюза в файлы, а `agentgate
fixtures <dir>` отдаёт их и браузеру, и серверному рендеру, так что экрану ничего за спиной не нужно.

То, что продукт намеренно показывает иначе, называется в файле исключений, каждая запись с причиной:
`{"ignore": {"<метка>": "почему"}, "dynamic": ["<метка>"]}`.

## Ограничения

`figma pull` работает с доступом на просмотр, читая собственный граф сцены веб-приложения Figma: REST API и
MCP-сервер дают месту зрителя несколько вызовов в месяц. Этот граф — не опубликованный интерфейс: когда Figma
его изменит, команда остановится и скажет, какой части больше нет. Место разработчика (Dev seat) делает
пригодным официальный API.
