# Figma и проверка вёрстки

[English](../design.md) · [Справочник toolkit](../../design-kit/README.md)

AgentGate выгружает доступный вам узел Figma в локальный пакет, измеряет реализацию и передаёт замеры вместе
со скриншотами независимому ревьюеру. При необходимости он запускает фронтенд с записанными ответами
GraphQL. Успешный замер — часть доказательств: сам по себе он не подтверждает внешний вид и поведение продукта.

## Подготовка

Основному AgentGate не нужны Node и браузер. Design-команды требуют Node.js 20+. REST-выгрузка Figma работает
без браузера; проверке вёрстки и браузерной выгрузке нужны `playwright-core` и Chromium.

Зависимости могут быть установлены вместе с browser tooling. Для исходников или полного архива:

```sh
npm ci --prefix design-kit --ignore-scripts --no-audit --no-fund
node design-kit/node_modules/playwright-core/cli.js install chromium
export PLAYWRIGHT_CORE="$PWD/design-kit/node_modules/playwright-core"
```

Явный путь к модулю позволяет встроенным в Go-бинарник инструментам использовать эту установку.
`AGENTGATE_BROWSER_EXECUTABLE=/path/to/chromium` выбирает Chromium для замеров. По умолчанию проверяется
браузер Playwright, затем распространённые системные пути. Браузерная выгрузка Figma использует Chrome или
Chromium Playwright и сохраняет выбранный канал вместе с профилем.

### Официальный REST API

Передайте `FIGMA_ACCESS_TOKEN` через окружение или менеджер секретов. Токену нужен доступ к файлу и scope
`file_content:read`. Затем:

```sh
agentgate figma frames 'https://www.figma.com/design/FILE/Name?node-id=1-2' --transport api --depth 2
agentgate figma pull 'https://www.figma.com/design/FILE/Name?node-id=1-2' --transport api --out screens/home/package
```

Адаптер использует документированные file/image endpoints, привязывает изображения к загруженной версии
файла, ограничивает размер ответов и параллельность загрузок. Ошибка доступа или лимита возвращается явно.
После HTTP 429 нет скрытого повторения запроса или перехода к браузеру. Токен передаётся только
`api.figma.com`; он не попадает на CDN изображений, к воркерам или в пакет. Квоты зависят от правил доступа и
тарифа Figma: [endpoints](https://developers.figma.com/docs/rest-api/file-endpoints/),
[rate limits](https://developers.figma.com/docs/rest-api/rate-limits/).

### Браузерная сессия

```sh
agentgate figma login
agentgate figma status
agentgate figma pull 'https://www.figma.com/design/FILE/Name?node-id=1-2' --transport browser --out screens/home/package
```

Вход открывает окно на вашем компьютере. Сессия хранится в
`${XDG_DATA_HOME:-~/.local/share}/agentgate/private/figma`; путь меняется через `AGENTGATE_FIGMA_HOME`.
Профиль скрыт от воркеров. `import-cookies <file>` позволяет импортировать вашу разрешённую экспортированную
сессию при отсутствии дисплея; входной файл содержит учётные данные, после импорта его следует удалить.

Адаптер читает внутренний граф сцены Figma и проверяет разрешение экспорта. Он сохраняет прежний сценарий,
но зависит от неопубликованного интерфейса: изменения Figma могут потребовать обновления адаптера. Это не
способ обхода прав доступа или запрета выгрузки.

Порядок выбора: `--transport`, затем `AGENTGATE_FIGMA_TRANSPORT`, затем API при наличии токена, иначе браузер.
`login`, `status`, `import-cookies` управляют только браузерной сессией.

## Выбор узла и пакет

`figma frames <url> --depth 2` выводит ограниченный каталог, `--json` — структурированные строки. Страница
или секция предназначена для навигации; выберите нужный frame/component через `--node <id>`.
`figma pull` выгружает узел, `--scales 2,3` добавляет размеры изображений, `--no-assets` отключает отдельную
выгрузку иконок и картинок. `figma node <package> <handle> --depth 3` раскрывает слой из краткого брифа.

| Файл | Назначение |
|---|---|
| `brief.md` | Краткое описание раскладки, шрифтов, цветов и меток слоёв |
| `frame.png` | Изображение выбранного узла |
| `context.png` | Родительский экран для проверки положения вложенного блока |
| `assets/` | SVG/PNG-ресурсы с устранением дубликатов содержимого |
| `data/nodes.json` | Исходное дерево в форме REST Figma |
| `data/spec.json` | Нормализованные данные для замеров |
| `manifest.json` | Источник, версия, геометрия, опись файлов и дайджест содержимого |

Выгрузка собирается и проверяется во временном соседнем каталоге под эксклюзивной блокировкой. Только после
этого она заменяет прежний пакет. Ошибка сохраняет предыдущую полную версию. Go-гейт и Node-проверка сверяют
обязательные файлы, пути описи и фактические байты. Изменение спецификации или изображения делает прежние
доказательства неактуальными даже при неизменённом поле digest. Повреждённый пакет нужно выгрузить заново.

## Экран и стенд

| Путь | Назначение |
|---|---|
| `.agentgate.json` | Общая настройка `design.stand` |
| `screens/home/screen.json` | URL, root и необязательные locale, viewport, device, cookies |
| `screens/home/package/` | Пакет макета |
| `screens/home/fixtures/` | Ответы GraphQL для состояния экрана |
| `screens/home/map.json` | Осознанные исключения и привязки слоёв к CSS-селекторам |

Добавьте в `.agentgate.json` конфигурацию запуска вашего проекта:

```json
{
  "design": {
    "stand": {
      "command": ["npm", "run", "dev", "--", "--host", "127.0.0.1"],
      "ready": "http://127.0.0.1:5173",
      "ready_timeout_s": 120,
      "graphql_env": ["VITE_GRAPHQL_URL"]
    }
  }
}
```

Пример `screen.json`:

```json
{
  "url": "/home",
  "root": "main",
  "viewport": "1440x900",
  "locale": "ru-RU"
}
```

```sh
agentgate layout screens/home --out artifacts/home
agentgate layout screens/home --record https://your-authorized-gateway.example/graphql
agentgate layout screens/home --keep
```

Стенд запускается, только если по `ready` нет сервера. В указанные GraphQL-переменные окружения передаётся
адрес локального сервера фикстур. Исправный существующий сервер используется и остаётся работать. Если он
отвечает ошибкой, команда сообщает об этом и не подменяет его. Для записи нужен управляемый новый стенд,
чтобы адрес GraphQL действительно можно было заменить.

Готовность ограничена таймаутом, журнал старта сохраняется. Обычное завершение, ошибка и отмена закрывают
только собственные процессы стенда и фикстур; при необходимости после TERM применяется KILL. `--keep`
намеренно оставляет запущенные процессы, печатает PID и путь журнала — их дальнейшую остановку выполняете
вы. `env_file` необязателен, но отсутствие явно указанного файла считается ошибкой.

`agentgate layout` получает итоговую конфигурацию репозитория экрана, включая расширения и личные настройки.
Прямой Node-запуск без AgentGate читает только проектный `.agentgate.json`.

## Фикстуры и запись

```sh
agentgate fixtures screens/home/fixtures --port 4317
agentgate fixtures screens/home/fixtures --record https://your-authorized-gateway.example/graphql
```

Сервер слушает loopback, проверяет имена операций и размер запросов. По умолчанию браузерные origin
ограничены локальной разработкой; `--origin <origin>` явно разрешает дополнительный. Записывайте только
данные и endpoints, к которым у вас есть доступ: JSON-фикстуры могут содержать данные приложения.

Новые записи адресуются по операции и каноническому хешу variables. Первый записанный пользователь или
страница больше не становятся ответом на все варианты запроса. Ручной `<Operation>.json` остаётся явным
универсальным ответом. Отсутствие фикстуры возвращает GraphQL-ошибку `FIXTURE_NOT_FOUND`.
`--allow-missing` сознательно разрешает пустые ответы для исследовательского запуска. HTTP-ошибки upstream
не сохраняются как успешные фикстуры.

## Замеры

Проверяются положение, размеры, шрифты, сплошные цвета, границы, радиусы и отсутствующие слои. Сопоставление
эвристическое: текст ищется по содержимому, блок — по геометрии. Отсчёт относительно найденного родителя
позволяет не дублировать одно смещение панели для каждого ребёнка. Современные CSS-цвета преобразуются
браузером в sRGB. Пиксельный отчёт учитывает отсутствующую или лишнюю площадь изображения.

Для пересекающихся или неоднозначных слоёв используйте `map.select`; селектор должен выбрать ровно один
элемент:

```json
{
  "select": {"hero-art": "[data-design=hero]"},
  "ignore": {"live-balance": "Реальные суммы отличаются от примера"},
  "dynamic": ["updated-at"]
}
```

Каждому ignore нужна причина. Исключения остаются предметом ревью. Замеры не доказывают автоматически все
состояния, семантику контролов, шрифты, градиенты и адаптивность.

Существующую страницу можно проверить без управления стендом:

```sh
agentgate layout screens/home/package --url http://127.0.0.1:5173/home --root main --viewport 1440x900 --out artifacts/home
```

Контракт уточняют `--storage-state`, `--wait`, `--locale`, `--device mobile`, `--tolerance`, `--max-pixel-diff`.
Для статических фикстур разрешён локальный URL `file:`. Выход: `report.json`, `report.md`, `actual.png`,
полная страница `page.png`, `marked.png`, `diff.png`.

| Код выхода | Значение |
|---|---|
| 0 | Измеренные свойства прошли проверку в рамках контракта |
| 1 | Есть измеренное расхождение или превышен пиксельный порог |
| 2 | Проверка не смогла выполниться; сначала исправьте вход/окружение |

## Гейт и baseline

План связывает дизайн с потоком: `design: [{"screen":"screens/home","stream":"frontend"}]`. До начала
работы гейт делает исходный замер, после работы повторяет проверку и передаёт независимому ревьюеру макет,
реализацию и контекст. Обязательные критерии: вид и кадрирование, положение в оболочке приложения,
семантика контролов, заявленные ширины и состояния. Числовой PASS их не отменяет.

`--write-baseline <file>` записывает точные исходные расхождения. `--baseline <file>` принимает только те же
сигнатуры при неизменном пакете, URL/root, viewport/device, locale, карте и допусках. Отсутствующая или
несовместимая baseline означает строгую проверку. Ещё не реализованная страница не получает разрешение
игнорировать все отсутствующие слои. У обычных командных проверок исходная ошибка всегда остаётся блокером.

Ошибочный контракт меняйте через `replan --plan <name>` с объяснением. Новая baseline после реализации не
должна скрывать регрессию. Для адаптивной задачи объявляйте промежуточные брейкпоинты и состояния: два
крайних снимка не доказывают работу всего диапазона.
