# Маршрутизация моделей и независимость

[English](../model-selection.md)

Имена моделей — настройка, а не основа архитектуры. Встроенная таблица рассчитана на аккаунты, которым
доступны указанные модели. Это стартовый профиль, а не рейтинг и не обещание доступности всех моделей
по вашей подписке. Действующую таблицу показывает `agentgate modes`; настройки проверяет
`agentgate config validate`.

## Что важнее выбора модели

1. Ревьюер не может использовать модель, которая писала любую часть изменения. Учитываются неудачные
   частичные попытки, замены по лимитам и предыдущие этапы. Сравниваются реальные идентификаторы моделей,
   поэтому второй алиас той же модели не обходит правило.
2. Замены используют только явно настроенные аккаунты и маршруты. Упоминание лимита в успешном ответе
   не считается исчерпанием квоты.
3. При продолжении сохраняются идентификатор сессии провайдера и фактическая директория запуска.
   Другой аккаунт того же провайдера может повторить попытку в этой сессии; если CLI её не принимает,
   ошибка сообщается явно. Замена модели при продолжении сессии отключена.
4. Усилие задаётся явно. Повторная проверка небольшого исправления может быть дешевле; повышение усилия
   связано с отсутствием прогресса, а не с универсальным рейтингом моделей.
5. Реальные маршруты и замены видны в результатах и панели. Независимость от автора обязательна;
   разнообразие производителей зависит от профиля и доступных замен.

## Стандартный смешанный профиль

| Роль | light | medium | heavy | ultra |
|---|---|---|---|---|
| Разведка | контекст лида | sol:medium | принятая архитектура | принятая архитектура |
| Архитектура | лид | лид | fable:high + astra:high | fable:xhigh + astra:xhigh, взаимная критика |
| Бэкенд | sol:medium | opus:medium | opus:high | opus:xhigh |
| Фронтенд | sonnet:medium | opus:medium | opus:high | opus:xhigh |
| Ревью архитектуры и простоты | лид | fable:medium | fable:high | fable:high |
| Ревью корректности | лид | astra:medium | astra:high | fable:xhigh + astra:xhigh |
| Ревью безопасности | — | — | — | astra:high |
| Потолок усилия | high | high | xhigh | max |

В heavy и ultra реализацию обеих частей пишет Opus. В прежней таблице Astra одновременно была автором
фронтенда и ревьюером корректности; смешанная задача нарушала требование независимости. Теперь Fable и
Astra остаются доступными для ревью до появления замен по квоте.

В таблицу намеренно не встроены цены, коэффициенты подписок и результаты бенчмарков. Они меняются
отдельно от инструмента и не доказывают, какая модель лучше для вашего репозитория. Настраивайте профиль
по времени выполнения, количеству исправлений и расходу квоты на похожих реальных задачах.

## Один провайдер

`agentgate setup install --lead codex` выбирает профиль только для Codex. В нём существенные изменения
пишет Astra, проверяет Sol, а Terra используется для дополнительной роли. Точную таблицу смотрите через
`agentgate modes` и в [профиле](../../internal/assets/profiles/codex.json).

Один провайдер не даёт межвендорного ревью. При этом сохраняются отдельные сессии, разные модели автора
и ревьюера, актуальные проверки и завершение по доказательствам. Для одной модели подходит light:
в этом режиме результат проверяет лид.

## Изменение маршрута

```sh
agentgate config set models.sol.model gpt-6.1-sol
agentgate config set modes.medium.backend sol:high
agentgate config set modes.medium.frontend sol:high
agentgate config validate
agentgate modes
```

Назначая автором модель, которая раньше проверяла код, измените и маршруты ревью. Если независимых
доступных ревьюеров не осталось, задача остановится с понятной ошибкой. Проверка конфигурации проверяет
структуру и связи настроек; она не делает платный запрос для проверки доступности каждой модели.

Меняйте по одной роли и сравнивайте похожие задачи: общее время, падения проверок, повторно открытые
замечания и соответствие первоначальным требованиям. Число параллельных процессов само по себе не
определяет стоимость или ёмкость подписки.

## Совместимость

Адаптеры используют официальные CLI:

- [Codex: non-interactive execution](https://developers.openai.com/codex/noninteractive/)
- [Codex CLI reference](https://developers.openai.com/codex/cli/reference/)
- [Claude Code CLI reference](https://code.claude.com/docs/en/cli-reference)
- [Claude Code headless usage](https://code.claude.com/docs/en/headless)

Провайдер может изменить модели, уровни усилия и события JSON. Тесты проверяют протокол на управляемых
фикстурах. Совместимость конкретной установленной версии и аккаунта окончательно проверяет небольшой
живой запуск. Ошибку протокола инструмент показывает как ошибку, а не как успешную работу агента.
